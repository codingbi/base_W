## 1. 产品概述
内控系统是一个面向行政事业单位的综合内部管理平台，整合了单位层面控制、风险管理、预算管理、收支管理、采购管理、资产管理、项目管理、绩效管理、合同管理等核心功能，旨在提升组织效率、实现高效运营、协同创新，打造可扩展的统一工作平台。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 系统管理员 | 系统预置 | 系统配置、用户管理、权限分配 |
| 单位领导 | 系统添加 | 全局数据查看、审批决策、报表分析 |
| 部门负责人 | 系统添加 | 本部门数据管理、审批流程、预算执行监控 |
| 普通员工 | 系统添加 | 业务操作、单据填写、查询个人相关数据 |

### 2.2 功能模块
1. **系统门户**：统一入口、工作台、消息中心、快捷入口、组织文化展示
2. **单位层面内控控制**：内控空间、组织架构、内控流程、沟通协调机制
3. **风险管理**：风险评估、风险识别、风险应对、风险监控
4. **预算管理**：收入预算、支出预算、预算编制、预算执行、预算调整
5. **收入管理**：收入登记、收入确认、收入分析、票据管理
6. **支出管理**：费用申请、报销审批、支出标准控制、资金支付
7. **采购管理**：采购预算、采购计划、采购申请、采购执行
8. **资产管理**：资产台账、资产配置、资产使用、资产处置
9. **项目管理**：项目立项、项目预算、项目执行、项目分析
10. **绩效管理**：绩效指标、绩效评估、绩效报告、绩效分析
11. **合同管理**：合同签订、合同履行、合同变更、合同归档
12. **BI报表决策分析**：数据大屏、多维分析、报表定制、数据导出
13. **内控移动应用**：移动填单、移动审批、项目展示、预算分析

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 系统门户 | 工作台 | 待办事项、已办事项、消息通知、快捷操作 |
| 预算管理 | 预算编制 | 预算录入、预算审核、预算汇总、预算上报 |
| 预算管理 | 预算执行 | 预算执行监控、预算执行分析、预算预警 |
| 支出管理 | 费用报销 | 报销单填写、报销审批、支付管理、凭证生成 |
| 项目管理 | 项目列表 | 项目信息展示、项目进度跟踪、项目预算控制 |
| BI报表 | 决策分析 | 数据可视化图表、多维度数据查询、报表导出 |

## 3. 核心流程
1. 用户登录系统 → 进入系统门户 → 查看待办事项 → 处理相关业务
2. 预算编制流程：预算填报 → 部门审核 → 财务审核 → 领导审批 → 预算发布
3. 费用报销流程：填写报销单 → 上传凭证 → 部门审批 → 财务审核 → 支付
4. 项目管理流程：项目立项 → 预算分配 → 项目执行 → 验收结项 → 绩效评估

## 4. 用户界面设计
### 4.1 设计风格
- 主色调：深蓝色 (#165DFF) 体现专业、稳重
- 辅助色：浅蓝 (#E8F3FF)、中性灰 (#F5F7FA)
- 按钮风格：圆角矩形，具有悬浮效果和点击反馈
- 字体：Inter + Noto Sans SC，层次分明，易读性强
- 布局风格：顶部导航 + 左侧菜单栏 + 右侧内容区，响应式设计
- 图标风格：简洁线性图标，与文字搭配使用

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|-------|
| 系统门户 | 英雄区 | 渐变背景、系统标题、核心功能入口卡片、动态统计数据 |
| 功能页面 | 内容区 | 卡片式布局、数据表格、图表组件、操作按钮组 |
| 详情页面 | 表单区 | 分组表单、必填项标识、保存/提交/取消按钮 |

### 4.3 响应性
- 桌面端优先设计，支持平板和移动端适配
- 左侧菜单在移动端可折叠为汉堡菜单
- 表格在小屏幕上支持横向滚动
- 表单字段在移动端垂直排列

### 4.4 交互设计
- 平滑的页面过渡动画
- 按钮和可点击元素的悬浮效果
- 加载状态和空状态的友好提示
- 数据变化时的微动画效果
